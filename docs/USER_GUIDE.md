# User guide

1. Browse **Find schemes** without an account. DEMO ONLY entries are fictional.
2. Register with an email and a password of at least 10 characters, including a letter and a number.
3. Open **Your profile** and provide only optional details you want to use for matching. Blank means unknown.
4. Open an active scheme and select **Check preliminary match**. Read each condition and the missing information, if any.
5. Save schemes for later or open **History** to compare saved assessments and rule versions.
6. Update a password or delete the account under settings. Deleting the account removes profile and assessment history.

Results are preliminary. Confirm eligibility with the relevant official authority.
